# Linear Algebra

## What is Linear Algebra?

Linear algebra is the mathematics that allows machine learning models to represent, transform, and calculate with numerical data.

| Machine learning task       | How linear algebra helps                                      |
|-----------------------------|---------------------------------------------------------------|
| Representing data           | Stores features in vectors and matrices                       |
| Linear regression           | Calculates predictions using weighted sums                   |
| Neural networks             | Transforms data using weight matrices                         |
| Image recognition           | Represents images and processes their pixel values            |
| Recommendation systems      | Represents users and items numerically                        |
| Natural language processing | Represents words and tokens as vectors                        |
| Transformers and LLMs        | Performs matrix multiplications and attention calculations   |
| PCA                         | Reduces the dimensionality of datasets                        |

## What should you learn first?

  1. Vectors: Understand how data points, model weights, and embeddings are represented.
  2. Dot products: Understand how models combine input features to make predictions.
  3. Matrix multiplication: Understand how models process entire datasets and transform representations.
  4. Vector norms and distances: Understand regularization, similarity, and distance-based algorithms.
  5. Linear transformations: Understand how neural network layers transform information.
  6. Eigenvectors, eigenvalues, and SVD: Understand the foundations of PCA and dimensionality reduction.

After these, study matrix rank, linear independence, least squares, and the relationship between linear algebra and gradients.

You do not need to master every advanced theorem before starting machine learning. Learn the mathematical concepts, implement them in Python, and connect each operation to a real algorithm.

The central idea to remember is this:

Data⟶Vectors and Matrices⟶Mathematical Operations⟶Predictions

During training, the model also uses its prediction errors to update its parameters. Linear algebra provides the computational foundation for these operations.

Once you understand how vectors, matrices, dot products, and matrix multiplication work together, many machine learning algorithms become much easier to understand.

Start by mastering vectors, dot products, matrix multiplication, and linear regression. Then move to gradient descent, PCA, neural networks, and finally Transformer attention. This sequence gives you the strongest practical foundation for ML.
